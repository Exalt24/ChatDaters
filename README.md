# ChatDaters

A dating platform with Tinder-style swipe matching, match detection, and in-app messaging. Built solo in a three-day sprint during my Full Stack Developer internship at ChatGenie.PH (Techstars '23, July 2024).

Users swipe through profiles, get matched when interest is mutual, and message each other once matched.

## Features

- **Swipe matching** — Tinder-style like/pass with mutual-match detection.
- **Match and message data** — matches and messages are stored and served over GraphQL and are read when a page loads or is refreshed. Live push over WebSockets is not built: Action Cable is generated by Rails but has no channel or subscription.
- **In-app messaging** — chat threads open automatically between matched users.

## Tech Stack

- **Backend:** Ruby on Rails GraphQL API (Action Cable is present as the Rails default only)
- **Frontend:** Vue 3, Vite, Tailwind CSS, Apollo client

## Structure

This is a monorepo merged from the two original repositories (with full git history preserved):

```
backend/    Ruby on Rails GraphQL API
frontend/   Vue 3 + Vite + Tailwind single-page app
```

## Getting Started

**Backend**

```bash
cd backend
bundle install
rails db:create db:migrate
rails server
```

**Frontend**

```bash
cd frontend
npm install
npm run dev
```
